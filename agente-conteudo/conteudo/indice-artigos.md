# Índice de artigos

Código de referência para pedir alterações no chat (ex: "Artigo 1, refaça a abertura").

Cada pilar é organizado em cluster: 1 artigo educativo base (abrangente, fundamento do tema) e 2 ou mais artigos de apoio (caso ou subtema específico, linkando de volta para o artigo base do pilar).
